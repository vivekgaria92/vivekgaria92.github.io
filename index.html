Content

Every reel is built from a fixed set of story beats — myth correction, the clinical mechanism, a concrete diagnostic threshold, an explicit "a machine doesn't diagnose you" line, hope, and a call to action — but never the same opening twice. Carousels run in English; reels stay Hinglish, because that's where the audience actually lives. One line closes every single video: "Apna khyaal rakhie, because mental health bhi health ka hi hissa hai."

Funnel

A 15-second reel becomes a booked session in four steps: Content pulls someone in, condition pages build Trust, a validated self-screen (GAD-7, ASRS-v1.1, PHQ-8) turns curiosity into an Assessment, and an AI chatbot carries the result straight into a booked Consultation — no form, no drop-off.
